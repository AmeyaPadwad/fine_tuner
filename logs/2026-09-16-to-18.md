- **Project decision and Gemma study (4 hrs).** Chose the Gemma track and am
  building around FunctionGemma
  (https://ai.google.dev/gemma/docs/functiongemma/model_card). The project
  is "Fine-tune FunctionGemma 270M for tool selection." The question is
  whether a model this small can choose tools reliably enough to take tool
  routing away from the main agent. I chose it for three reasons. First, it
  is a 270M model meant to be fine-tuned for one narrow task, so I can train
  and test it on modest hardware without a large GPU setup. Second, Google
  publishes a dataset and a fine-tuning recipe, which gives me a working
  baseline to adapt, and the model card reports 58% before fine-tuning and
  85% after on its Mobile Actions task, so improvement is easy to measure.
  Third, success can be checked automatically by running the selected tool
  in a sandbox, and the project includes an explicit no-tool option, which
  fits the Optimus loop of environment, reward, and evaluation.
  Read the FunctionGemma formatting guide
  (https://ai.google.dev/gemma/docs/functiongemma/formatting-and-best-practices)
  and fine-tuning guide
  (https://ai.google.dev/gemma/docs/functiongemma/finetuning-with-functiongemma).
  I also read the Gemma 4 overview (https://ai.google.dev/gemma/docs/core),
  its function calling page
  (https://ai.google.dev/gemma/docs/capabilities/text/function-calling-gemma4),
  and the Unsloth training guide (https://unsloth.ai/docs/models/gemma-4/train)
  to see how the newer family handles tool use.
